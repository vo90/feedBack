# Timed finger vibrato

The additive `vibrato_marks` note field preserves finger-vibrato intervals. It
applies equally to standalone notes and chord children:

```json
{"t":10,"s":3,"f":14,"sus":2,"vb":true,
 "vibrato_marks":[{"start":0.5,"end":1,"intensity":"slight"},
                  {"start":1,"end":2,"intensity":"wide"}]}
```

`start` and `end` are finite seconds relative to the owning attack; intervals
must be positive, ordered, nonoverlapping and inside its sustain. Intensity is
`slight` or `wide`. An absent field retains legacy `vb`/`vibrato` behaviour. A
present empty array explicitly disables whole-note vibrato. Malformed data is
rejected at the wire boundary, rather than interpreted as legacy vibrato.
Microsecond precision is retained for the note or owning chord's onset and the
sustain. The usual serialization tolerance at the final endpoint is 1.1 us.

The 3D highway animates only within these intervals, around the existing bend.
Adjacent intervals share phase and smoothly change strength; real gaps stop it.
The familiar slight wave uses the existing period; wide is 1.5 times its visual
amplitude. These are display conventions, not measured pitch or speed. A smooth
edge envelope fits within even very short intervals. Array-keyed weak caches
store contiguous run extents, and sampling uses a binary interval lookup. Loaded
chart arrays are immutable; replacement arrays receive fresh cached runs.

The chord drawing scratch clears/replaces the field on every reuse. Existing
string inversion, left-handed placement, slide-out paths, tapering, and trail
visibility remain responsible for their respective geometry. Legacy linked-note
vibrato keeps its existing continuity rules. Explicitly timed notes are excluded
from legacy whole-note runs.

No attacks, sustain lengths, bend curves or scoring targets are generated by
this display field. No note-detection change is required. Source notation remains
the authority for the tab view; this extension does not rewrite written ties.

FeedForge preservation contract 62 emits this field and independently checks it
against retained Songsterr source. Older game versions may ignore the extension
and show their legacy whole-note `vb` display, so use the matching updated game.
